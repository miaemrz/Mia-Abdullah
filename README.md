# Mia Emmylia — Finance Portfolio

A responsive, editable one-page portfolio designed for GitHub Pages.

## Preview locally
Open `index.html` in a web browser.

## Publish free with GitHub Pages
1. Sign in to https://github.com/
2. Create a **public** repository named `YOUR-GITHUB-USERNAME.github.io` (replace with your actual GitHub username).
3. Upload `index.html` to the repository root and commit the change.
4. Open the repository's **Settings → Pages**. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
5. Wait for GitHub Pages to publish. Your site address will be `https://YOUR-GITHUB-USERNAME.github.io/`.

## Personalise before publishing
- Replace `YOUR.EMAIL@example.com` with your professional email.
- Add your LinkedIn URL (you can add it beside the email button).
- Add real screenshots or PDFs of your projects if you have them.
- Confirm exact project titles and the investment simulation's official name before naming it more specifically.
- Keep all skill claims accurate and be ready to explain each one in an interview.
